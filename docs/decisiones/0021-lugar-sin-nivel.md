# 0021. Lugar sin nivel de privacidad: dirección completa

- Fecha: 2026-10-01
- Estado: Aceptada

## Contexto

0005 define cuatro niveles de privacidad por lugar. Faltaba qué se muestra si no se elige
ninguno.

## Decisión

- Sin nivel elegido, se muestra la **dirección completa**.

## Descartado

- Un valor por defecto más cerrado (solo nombre o solo barrio).

## Consecuencias

- En #137. Para ocultar algo, se elige el nivel a propósito, en el lugar o en el evento.
